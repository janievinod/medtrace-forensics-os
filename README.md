# MEDTRACE – Healthcare × Digital Forensics OS

> AI-Powered Healthcare Digital Forensics Platform designed to detect unauthorized access, insider threats, abnormal EHR activity, and potential data exfiltration.

## 🚀 Overview
MEDTRACE is a responsive, single-file frontend application built with Tailwind CSS, Lucide icons, and a dynamic JavaScript component engine. It simulates real-time security telemetry, AI-driven anomaly detection (Isolation Forest), cryptographic record integrity checks, and interactive SOC (Security Operations Center) investigation timelines.

## ✨ Key Features
- **Executive Security Dashboard:** Real-time threat telemetry, critical alerts counters, and high-risk user metrics.
- **Live SOC Simulation Engine:** Automated background simulations triggering live critical alert popups with countdown telemetry.
- **Investigation Timeline:** Deep forensic session reconstruction tracking logins, device handshakes, database queries, and bulk data exports.
- **Graph & AI Reports:** Simulated cluster entity relationship mapping (Neo4j) and automated Google Gemini AI forensic reports.
- **Customizable Platform Settings:** Configurable anomaly detection thresholds and auto-quarantine rules.
